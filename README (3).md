# NEON STRIKE v1.5.1

NEON STRIKE는 Three.js 기반 브라우저 FPS 프로젝트입니다. 온라인 1대1, 계정/레벨 저장, 총기 구매와 라운드 경제, Neon Points 상점과 스킨, 훈련장 기능을 포함합니다.

## 로컬 실행

필요 사항: Node.js 20.19 이상, 인터넷 연결(최초 의존성 설치 시).

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 주요 기능

- 온라인 1대1 방 코드 방식 및 6승 선취 라운드
- 훈련장 과녁/더미, 킬 후 5초 카메라 연출
- 10종 무기 모델과 GLB 로딩 실패 시 절차적 대체 모델
- 상점 번들, 오늘의 스킨, 스킨 뽑기, 코드 입력 및 반복 퀘스트
- 계정 비밀번호 해시, 계정별 XP/Neon Points/보유·장착 스킨 저장

## 데이터베이스

배포 환경은 Render 웹 서비스의 `DATABASE_URL` 환경변수에 Neon PostgreSQL의 pooled connection string을 등록해야 합니다. 연결 문자열 또는 비밀번호를 코드나 GitHub에 저장하지 마세요. `/healthz`에서 `accounts: "ready"`인지 확인할 수 있습니다.

## v1.5.1 변경 사항

- 상점·스킨·퀘스트 UI 스타일과 모바일 레이아웃 보강
- 훈련 표적이 온라인 경기로 남아 있지 않도록 온라인 진입/라운드 갱신 시 정리
- 크레딧 보상을 높이고 라운드가 진행될수록 추가 보상 지급
- 무기 슬롯 상태 업데이트를 누적 방식으로 바꿔 2/3번 전환 시 구매한 주무기가 클라이언트 목록에서 사라지는 문제 보완
- 서비스 워커 캐시 버전을 올려 최신 UI를 더 안정적으로 불러오도록 변경

## 점검

`npm run check`는 서버와 클라이언트 JavaScript 문법을 검사합니다. 배포 후에는 PC와 모바일 등 서로 다른 두 기기에서 온라인 대전, 다음 라운드, 킬캠, 상점 및 계정 저장을 실제로 확인하세요.
